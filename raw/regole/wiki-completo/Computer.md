=Computer=
Si è in grado di far funzionare, manipolare e hackerare i sistemi informatici. Se non si ha fisicamente accesso all'interfaccia utente di un sistema informatico, si deve utilizzare un [[Equipaggiamento/Kit di Attrezzi|Kit da Hackeraggio]] per accedere al sistema e manipolarlo.
__TOC__
I [[Equipaggiamento/Computer#Computer|Computer]] sono configurati per concedere a uno o più utenti autorizzati degli “[[Equipaggiamento/Computer#Accesso di Root|Accessi di Root]]”, che consentono loro di raggiungere qualsiasi informazione o funzione del computer come [[Azione Standard]], senza bisogno di effettuare prove di Computer. I [[Equipaggiamento/Computer#Firewall|Firewall]] possono isolare determinate sezioni di un computer e concedere a diversi utenti l'[[Equipaggiamento/Computer#Accesso di Root|Accessi di Root]] a tali sezioni. La [[CD]] base per molti compiti dell'abilità Computer è pari a 13 + (4 x la categoria del computer). Queste [[CD]] possono venir modificate dal [[GM]] per tenere conto di altre circostanze.
==Accedere a Sistema Non Protetto==
Come [[Azione Standard]] si può utilizzare l'abilità Computer per accedere alle funzioni più basilari di un sistema informatico non protetto. La [[CD]] per accedere alle informazioni o funzioni di un computer pubblico privo di contromisure o firewall è in genere 10. A differenza degli altri compiti dell'abilità Computer, si può tentare di accedere a un sistema senza addestramento se si [[Abilità#Prendere 20|Prende 20]] alla prova, il che richiede 2 minuti. È possibile accedere ai sistemi informatici protetti, e alle sezioni protette di un sistema non protetto, effettuando una prova di Computer per [[#Hackerare Sistema|Hackerare un Sistema]].

==Creare o Riconoscere un Falso==
Si può utilizzare l'abilità Computer per falsificare documenti ufficiali. Ciò richiede 1d4 minuti. Il [[GM]] effettua in segreto la prova di Computer per creare un falso, di modo che non si può essere certi di quanto convincente esso risulti. Questa prova è contrapposta alla prova di Computer effettuata da chiunque esamini il documento per stabilirne l'autenticità. La [[CD]] per le prove di Computer per riconoscere un falso variano in base al tipo di documento falsificato e vengono modificate da altre circostanze stabilite dal [[GM]], come mostrato nella seguente tabella.
==Disattivare o Manipolare Modulo==
Un personaggio con accesso di root a un computer può disattivare o manipolare una contromisura o un modulo con un'[[Azione Standard]], superando una prova di Computer con [[CD]] 10. Se si ha accesso (ma non di root) a un computer, è possibile effettuare una prova di Computer per attivare, aggiungere, disattivare o manipolare qualsiasi contromisura o modulo. Se si vuole agire su una contromisura o un modulo protetto da un firewall, come prima cosa è necessario [[#Hackerare Sistema|Hackerare il Sistema]] in modo da accedervi. Attivare o disattivare una contromisura o un modulo in genere richiede un'[[Azione Standard]]. Aggiungere o rimuovere un modulo generalmente richiede 1 minuto per categoria del computer. Tutte queste azioni prevedono una [[CD]] pari alla [[CD]] per [[#Hackerare Sistema|Hackerare il Sistema]]. Non è possibile [[Abilità#Prendere 20|Prendere 20]] in una prova di Computer per disattivare o manipolare un modulo.
==Distruggere o Riparare un Sistema o Modulo==
Si può utilizzare Computer per riparare un sistema informatico o un modulo che sia stato disattivato, o per distruggerne uno che sia stato rimosso o disattivato, trascorrendo 10 minuti per categoria del sistema informatico a lavorare sul computer in questione. La [[CD]] è basata sulla categoria del sistema informatico. Se si sta riparando un modulo o un sistema disattivato e si fallisce la prova di 5 punti o più, si distrugge accidentalmente il modulo o il sistema. Non è possibile [[Abilità#Prendere 20|Prendere 20]] in una prova di Computer per distruggere o riparare un sistema informatico.
==Fabbricare Computer==
Se si possiedono abbastanza gradi nell'abilità Computer, è possibile Costruire dei Computer. Vedi [[Merci e Servizi#Creare Equipaggiamento e Oggetti Magici|Le Regole sulla Fabbricazione degli Oggetti]].
==Hackerare Sistema==
Si può utilizzare l'abilità Computer per hackerare un sistema informatico a cui non si ha già accesso. In genere hackerare un computer richiede un'[[Azione Completa]] per categoria del sistema informatico. È possibile dimezzare questo tempo (fino a un minimo di un'[[Azione Completa]]) per ogni 5 punti di cui si supera la [[CD]] della prova di Computer. In caso di successo nella prova, si accede a qualsiasi parte del computer che non sia protetta da un [[Equipaggiamento/Computer#Firewall|Firewall]]. Ciò consente di utilizzare le funzioni di base del computer e di effettuare ulteriori prove per le quali sia richiesto di avere accesso. Per accedere alle parti di un computer protette da un firewall occorre effettuare una prova di Computer aggiuntiva per ciascun firewall. Se si fallisce una prova di Computer per hackerare un sistema, c'è la possibilità che si attivi una contromisura, se nel sistema ne è stata installata una. Se si [[Abilità#Prendere 20|Prende 20]] in una prova per hackerare un sistema dotato di contromisure senza prima disattivarle o distruggerle, le contromisure vengono attivate automaticamente.
==Identificare Falso Shell==
Se si ha l'accesso a un computer, ma non l'accesso di root, esiste la possibilità che in realtà ci si sia autenticati in un [[Equipaggiamento/Computer#Falso Shell|Falso Shell]]. Nel caso si superi la prova, che richiede un'[[Azione Completa]], ci si rende conto di aver eseguito l'accesso a un [[Equipaggiamento/Computer#Falso Shell|Falso Shell]]. La [[CD]] è pari a quella per hackerare il computer +5 (vedi [[Equipaggiamento/Computer#Categorie|Tabella: Categorie di Computer]]).
==Ottenere Accesso di Root==
Se si ha accesso a un computer, si può tentare di aggiornare le proprie autorizzazioni per ottenere un accesso di root. La procedura è simile a quella per hackerare quello stesso computer, ma la [[CD]] è aumentata di 20. In molti casi è impossibile ottenere l'accesso di root, e ogni azione che vada oltre l'utilizzo delle funzioni basilari del computer deve essere effettuata come prova separata per distruggere, riparare, disattivare o manipolare moduli o contromisure. Se un firewall è stato configurato per prevedere un distinto insieme di utenti autorizzati con permessi di root, si deve ottenere separatamente accesso di root a esso. Una volta eseguito l'accesso di root a un computer, è possibile stabilire a chi altro concedere o non concedere l'accesso di root superando una prova di Computer per hackerare il sistema.
